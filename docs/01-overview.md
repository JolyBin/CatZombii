# 01 — Обзор

*Срез: 1 августа 2026, Unity 6000.5.3f1*

## Что это за игра

**CatZombii** (в настройках проекта — `ZombiiCat`) — гибрид головоломки и автобоя
для WebGL на площадке Яндекс.Игры. Тема: коты против зомби.

Игрок не атакует напрямую. Он решает пазл, а решения пазла превращаются в заклинания,
которые сами применяются к идущему параллельно бою.

## Основной цикл

```
   ┌─────────────────────────────────────────────────────────────┐
   │  6 колб, в каждой до 4 шариков-элементов                     │
   │  клик по колбе → взять верхний шарик                         │
   │  клик по другой → перелить                                   │
   └───────────────────────────┬─────────────────────────────────┘
                               │ колба из 4 ОДИНАКОВЫХ схлопывается
                               ▼
   ┌─────────────────────────────────────────────────────────────┐
   │  СТОЛ: накапливается последовательность элементов (до 6)     │
   │  игрок сам решает, когда нажать «проверить»                  │
   └───────────────────────────┬─────────────────────────────────┘
                               │ последовательность ищется в книге героя
                               ▼
        ┌──────────────────┴──────────────────┐
        │ совпало                              │ не совпало
        ▼                                      ▼
   заклинание применяется к бою          элементы сгорают впустую
        │
        ▼
   ┌─────────────────────────────────────────────────────────────┐
   │  БОЙ идёт в реальном времени, независимо от пазла:           │
   │  враги бьют по своим кулдаунам, у героя тикает HP            │
   │  волна зачищена → следующая; все волны → победа              │
   └─────────────────────────────────────────────────────────────┘
```

Ключевое напряжение: **пазл не ставит бой на паузу**. Пока игрок соображает,
как переливать шарики, зомби продолжают бить. Плохое решение пазла = потерянные HP.

## Глоссарий

| Термин | В коде | Что это |
|---|---|---|
| Элемент | `Element` | Стихия-шарик. Всего 7, у каждого свой `ID`, спрайт и цвет. |
| Колба | `Flask` / `UIFlask` | Стек до 4 элементов. 4 одинаковых → схлопывается. |
| Стол | `Table` / `TableController` | Накопитель собранных элементов + поиск комбинации. |
| Книга | `Book` | Набор комбинаций конкретного героя. Книга ≈ герой ≈ класс. |
| Комбинация | `Combination` | Упорядоченная последовательность элементов → заклинание. |
| Заклинание | `BaseSpellConfig` → `BaseSpell` | Конфиг-ассет + рантайм-объект, применяющий эффект. |
| Юнит | `UnitConfig` → `UnitRuntime` | Враг или союзник: HP, кулдаун атаки, приоритет цели. |
| Волна | `Wave` | Пачка юнитов + лечение героя перед началом. |
| Уровень | `BattleConfig` | Фон + последовательность волн. |
| Партия | `StepsController` | Один заход в бой: колбы + стол + бой вместе. |

## Что запускается прямо сейчас

Сцена `Assets/Scenes/SampleScene.unity`, `GameManager` на объекте `Main Camera`.
В инспекторе выставлено:

- `_startBook` → **Warrior Book** (самая полная книга — дефолтный прогон рабочий);
- `_currentLevels` → **Level 1 … Level 7** (все семь, по порядку).

То есть игра проходится за Warrior'а на всех семи уровнях, включая единственный
боевой уровень с боссом. Весь собранный контент достижим из игры.

## Технический стек

- **Unity 6000.5.3f1** (поднят с 2022 — см. [08 — Инструменты](08-tooling.md)).
- **UniTask 2.5.10** — вся асинхронщина (таймеры атак, регенерация, стан). Вендорится в `Assets/Plugins/`.
- **DOTween** — анимации UI на столе. Лежит в `Assets/Plagins/` (опечатка в имени папки — так исторически).
- **TextMeshPro** — внутри `com.unity.ugui` 2.5.0.
- **PluginYG 2** (v2.0092) — SDK Яндекс.Игр, импортирован, но не подключён к игровому коду.
- **Layer Lab GUI Pro — FantasyRPG** — покупной UI-кит.
- Своих `asmdef` у игрового кода нет — всё в `Assembly-CSharp`.
